# Fanry 每日日报

每日 AI 行业新闻简报 + 具身智能行业热点新闻，聚焦技术进展与商业动态。

## RSS 订阅

```
https://fanrydavid.github.io/fanry-daily/feed.xml
```

将上述地址添加到任意 RSS 阅读器（Feedly、Inoreader、Reeder）即可订阅。每天推送一条 digest，包含 AI 新闻简报与具身智能行业热点。

## 内容来源

本日报整合了两个定时任务 的输出：
1. **每日 AI 新闻简报**（09:30 执行）- 覆盖 OpenAI、Google、Anthropic 等公司动态、融资并购、技术突破、行业标准
2. **每日具身智能新闻简报**（13:30 执行）- 覆盖机器人产品发布、融资事件、技术突破、标准规范
